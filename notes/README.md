# 学习记录目录

学习记录按照课程站的六个大阶段分组。目录编号、课号范围和课程站中的 `SECTION 01–06` 保持一致。

| Section | 课号 | 学习记录目录 |
| --- | --- | --- |
| 01 · 从复位到程序控制流 | 00–06 | [`01-从复位到程序控制流`](01-从复位到程序控制流/) |
| 02 · 进入 x86-64 Long Mode | 07–11 | [`02-进入x86-64-Long-Mode`](02-进入x86-64-Long-Mode/) |
| 03 · 加载、交接与 ELF | 12–14 | [`03-加载交接与ELF`](03-加载交接与ELF/) |
| 04 · 启动复盘与理解检验 | 15–17 | [`04-启动复盘与理解检验`](04-启动复盘与理解检验/) |
| 05 · C 内核与 Bootloader 毕业 | 18–24 | [`05-C内核与Bootloader毕业`](05-C内核与Bootloader毕业/) |
| 06 · Limine 与内核主线 | 25 起 | [`06-Limine与内核主线`](06-Limine与内核主线/) |

文件名继续使用 `note-NN.md`，因此课程编号和学习记录仍可直接对应。`note-31.5.md` 属于第 06 阶段。

新增课程时，先在 `site/scripts/sync-content.mjs` 的 `lessonMeta` 中登记课程；同步脚本会根据 Section 的课号范围，
自动从对应阶段目录读取笔记。
